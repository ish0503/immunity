# 면역 실험실

항원(적혈구·바이러스·세균·원생생물·백신)을 끌어다 몸속에 넣고, 외부 방어 → 선천 면역 → 특이적(적응) 면역이 어떻게 반응하는지 관찰하는 교육용 웹 시뮬레이션 게임입니다. 서버 없이 HTML/CSS/JavaScript만으로 동작합니다.

## 실행

- 로컬: `index.html`을 브라우저로 열면 됩니다 (빌드·설치 불필요).
- GitHub Pages: 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`** 로 저장하면 `https://<사용자명>.github.io/immunity/` 에서 열립니다.
  - 비공개 저장소에서 Pages를 쓰려면 GitHub Pro/Team 이상 요금제가 필요합니다. 무료 계정이면 저장소를 공개로 바꿔야 합니다.

## 구현된 면역 체계

| 단계 | 내용 |
|---|---|
| 1차 방어 (외부 장벽) | 피부 각질층·피지·라이소자임, 호흡기 점액·섬모 운동, 위산. 상처·혈관(주사·수혈·모기) 경로는 장벽을 건너뜀 |
| 2차 방어 (선천 면역) | 비만세포 히스타민 → 염증·혈관 확장, 호중구·대식세포 탐식(고름 형성), 단핵구 동원, 보체(MAC·옵소닌화), 인터페론·항바이러스 상태, NK세포(MHC I 소실 감지), 사이토카인 발열 |
| 3차 방어 (특이적 면역) | 수지상세포의 항원 포획·림프절 이동, MHC II → 보조 T세포, MHC I 교차 제시 → 세포독성 T세포, B세포 활성화 → 형질세포, IgM → IgG 클래스 전환·친화도 성숙, 기억 B·T세포 |
| 2차 면역 반응 | 기억세포 수·민감도에 따라 더 빠르고 강한 반응 (오른쪽 항체 그래프로 비교) |

## 항원 종류와 전략

- **적혈구**: A/B/Rh(D) 항원. 몸의 혈액형을 고르면 자연 항-A/항-B IgM이 존재 → 부적합 수혈 시 응집·보체 용혈. Rh−에게 Rh+ 수혈은 1차엔 감작, 2차엔 빠른 IgG 반응.
- **바이러스**: 리노바이러스(발열에 약함), 인플루엔자(항원 소변이), 노로바이러스(위산 저항), 단순포진(MHC I 은폐·신경절 잠복·재활성화), HIV(보조 T세포 감염, 면역 회피 변이, 잠복 저장소 → AIDS와 기회 감염).
- **세균**: 황색포도상구균(호중구 독소·고름), 폐렴구균(협막 → 항체 옵소닌화 필요), 살모넬라(위산에 약함·LPS 발열·보체에 약함), 결핵균(대식세포 내 생존, Th1 활성화·육아종·잠복).
- **원생생물**: 말라리아(간 단계 → 적혈구 내 은신, 주기적 발열·빈혈), 트리파노소마(VSG 항원 변이로 감염의 파도), 이질아메바(포낭 위산 저항, 접촉 세포 용해).
- **백신**: 인플루엔자·폐렴구균 — 증식 없이 기억세포만 만들어 둠.

투입량을 ‘압도적’으로 하거나 HIV를 넣으면 면역 체계가 무너지는 장면도 볼 수 있습니다.

## 파일 구성

- `index.html`, `css/style.css` — 화면
- `js/data.js` — 지형·항원 정의
- `js/sim.js` — 시뮬레이션 엔진 (DOM 없이 Node에서도 실행 가능)
- `js/render.js` — 캔버스 그리기
- `js/ui.js` — 드래그·패널·그래프

실제 면역 체계를 단순화한 모델이며 수치는 교육용으로 조정한 값입니다.
